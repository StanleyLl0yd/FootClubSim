# M1 P3 v166 — optional combined fictional referee and manager source

The opt-in v166 adapter composes independently generated v19 fictional
referee sanctions/withdrawals and v158 manager-selected normal substitutions
into **one v105 physical chronology**. Unlike two separately committed
simulations, their action order, active physical XI, events and final report
are evaluated together. The canonical career fixture seed, exact generated
referee commands, manager command identities and the full v120 CAS journal
are checked independently on both write and historical replay.

At an in-play substitution boundary the pre-existing v158 no-referee goal
source must be valid, **and** a newly replayed combined prefix including
earlier sanctions and substitutions must contain the actual generated goal
immediately preceding that boundary. At halftime no goal is fabricated.
Unsupported collisions, absent players or inconsistent merged results fail
closed, rather than generating a substituted whistle.

This intentionally conservative prototype may refuse a legal combined
in-play stoppage if it was absent from the narrower v158 base proposal.
It is **not** a finished clock/referee engine, live UI interaction,
medical clearance, KDK sanction authority, automatic season progression,
opponent-wide history, calibrated randomness or a P3-1 gate acceptance.
The 2024/25 holdout remains sealed; original M0/v8/v120 schemas and
game RNG probabilities are unchanged. P3 0/4, P5 0/5, M1 OPEN, M2 forbidden.

## Separate experimental browser action

The dense v120 browser panel can offer explicit combined-source actions for
one, two, or three-to-five manager-selected substitutions, reusing the
existing player/time selectors. Each one-shot action submits a full
source-checked match and atomic CAS proposal, not an interactive live clock.
The older ordinary, virtual-only, manager-only and verified-goal-stop actions
remain distinct. If combined source replay cannot prove an allowed action,
the UI displays a rejection instead of committing an unverified match.
