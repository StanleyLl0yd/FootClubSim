# Experimental M1 v190 internal special-goal adapter (not playable)

**Research only.** No change to the v188 match producer, v188 source replay/validation, stored journal bytes, player UI, match scores or current M2 rule pack. The actual playable code path in `src/core/m1-v182-unified-source.ts` passes an empty `trustedDecisions` array into v105, so its automatic penalties and own goals are structurally absent. [P5 finding #31](https://github.com/StanleyLl0yd/FootClubSim/issues/31).

This isolated `src/core/m1-v190-experimental-special-goals.ts` uses a new independent FNV-1a seed namespace (the match's versioned seed, immutable fixture ID and string `/v190`) and the existing deterministic 270-draw open-play source. It derives actual source-clock snapshots using v179, chooses only on-pitch **outfield** actors at legal 300-second decision checkpoints, and proposes its versioned synthetic decisions to the already replay-verified v105 goal/penalty attribution, score and restart logic. Each proposed decision is independently rechecked against the full physical chronology. Unavailable actors or rejected speculative rulings are **omitted without aborting a valid match**. This is a deterministic, fail-closed event gate, not an externally authenticated referee. The original open-play seed/RNG state is checked unchanged. Revalidation is by full deterministic replay, not a caller-supplied assertion.

**Exploratory trigger parameters**: one possible penalty at probability `0.26` per fixture, one possible own goal at `0.06`, penalty result scored/saved/missed at conditional `0.75/0.15/0.10`. These are arbitrary smoke-test values, **not measured 2026/27 RPL rates** and must never be used as "calibrated" gameplay constants. This model has no proved foul, penalty-area location, challenge sequence, VAR or independent legal referee authority. Its result explicitly says `genuineFoulAndBoxPositionSource:false`, `internalDecisionModelAuthenticated:false`, `historicalV188SaveAdmissionAllowed:false` and `releaseCalibrationAccepted:false`.

The targeted test seeds `1,2,17,79` establish deterministic coverage of penalty-only, neither, own-goal-only and both events with the same `a-0-0` test fixture, physical actor eligibility, non-colliding chronology, score conservation and strict tamper rejection. Nothing is injected into the existing v188 career. The next engineering stage is a *causally sourced* virtual referee with legitimate foul-location evidence, schedule/penalty retakes, injured/suspended player availability, a new journal schema/source version and fully backward-compatible archive import before any playable integration. Then independently seeded source-replayed, mirrored and rights-reviewed comparison cohorts, with pre-registered acceptance limits. **M1 P3/P5, M2 and #155 remain open.**
