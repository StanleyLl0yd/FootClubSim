# M1 P3 v138 — three to five ordinary substitutions, domain-only

Adds a separate three-to-five command source-replayed dense fixture adapter.
A legal halftime batch does not consume an in-play opportunity, and
same-checkpoint multiple changes count as one opportunity. Physical source
replay through the original v105 engine verifies active XI, bench, goalkeeper,
foreigner cap, up to five normal replacements and no more than three distinct
non-half-time substitution windows. Strict v126 source namespace checking
prevents manager commands from masquerading as modelled referee incidents.

This is a core/domain step, **not a new UI capability**. The existing browser
still exposes at most two selected normal substitutions. Additional UI,
native browser acceptance, external referee/KDK/doctor authority, concussion
and exceptional procedures, complete opponent source history and full P3
acceptance remain open. No changes to M0/v8 persistence or PRNG.
2024/25 holdout unused; no historical score fitting. P4 deferred, M2
forbidden. M1/P3/P5 and both exit audits remain open.
