# M1 P5 v141 — record career-cluster rather than fixture-level uncertainty

This independent source-replayed research emits one observed row per
**seed career**, retaining its up-to-four correlated fixtures as a
cluster. The new runner calls the unchanged v131 source verification
once per career, retains all original event counters and category
limitations, and tests that adding independent career rows reproduces
the original v131 aggregate exactly.

An eight-shard, least-privilege GitHub workflow records the actual
original 64 careers in groups of eight, a full line of JSON per shard
and SHA-256. The data must be retrieved from the real successful
workflow logs before any claims about actual observed results.
This is the prerequisite for career-cluster-aware uncertainty
estimation; it **does not** yet compute a confidence interval, set
reference thresholds, prove provider category alignment or accept P5.
Four fixtures from one seed are NOT four independent observations.

The model's synthetic referee events are not externally authenticated
disciplinary or clinical records. No weights, PRNG, M0/v8 save formats
or original v131 report are changed. No 2024/25 holdout access or
historical-score/winner matching is requested. M1/P3/P5 and both
repository-wide exit audits remain OPEN; P4 deferred, M2 forbidden.
