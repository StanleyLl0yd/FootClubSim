# M1 P5 v100 - versioned intraphase shot-event census

This opt-in study replays **240 fixture positions x 8 fixture-domain-separated
SHA256 research seeds = 1920 source-v99 matches**, split across 16 exact-head
GitHub Actions shards. No aggregate outcome is hardcoded.

Each result must come from the versioned 100-second source. The original
actor/prematch gate is enforced; source schema 99 has 270 deterministic RNG
draws and full-time at second 5400. The study independently counts goal,
saved, blocked and off-target events and checks the source ledger. It fails
closed for non-monotonic event order, incomplete shards, seed collisions,
unrecognized outcomes, and any violation of goals + saves + blocked +
off-target = attempts, on-target = goals + saves, or attempts > 54.

The pinned independent [Sport-Express RPL 2025/26 reference](https://www.sport-express.ru/football/n/russia/premier/2025-2026/statistics/common/)
covers 240 real matches with 5548 shots, 1879 on target and 609 final-score
goals of all types. The model's v99 goals are **open-play only**.
Definitions for blocked attempts and on-target shots are not yet
harmonized with the publisher. Real xG is unavailable. Neither descriptive
on-target share is automatically Opta-style shooting accuracy.

Unlike older v90 hypothetical multi-opportunity experiments, v99 has a
new event schema and deterministic replay verifier. However v99 has
**no** live in-match substitutions, medical off-field actions, referee
decisions, penalties, own goals, verified clinical/KDK authority,
career CAS admission or release-ready frequency/quality calibration.
It must not be passed into the v76 career journal. No production source,
PRNG, M0, saved format, probability or existing career is changed.
The untouched 2024/25 holdout remains reserved for later validation.
