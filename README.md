# FootClubSim

**FootClubSim** - браузерный симулятор управления футбольным клубом. Первая игровая лига - российская Премьер-лига (РПЛ). Интерфейс изначально на русском языке.

> **Статус проекта: M0, фундамент в разработке.** Базовые модели, тесты и headless-библиотека TypeScript уже работают. Играбельного браузерного приложения и релиза пока нет.

## Концепция

Игрок выбирает клуб, управляет составом, расстановкой, тактикой, контрактами, трансферами, финансами и развитием команды. Матчи, включая встречи остальных клубов, **автоматически рассчитываются игровым движком**. В первых версиях нет графической визуализации матчей.

Игра рассчитана на долгосрочную одиночную карьеру, с сохранениями и развитием футбольного мира. Начинаем с РПЛ; другие соревнования могут использоваться в упрощённом виде для трансферов, повышения и вылета.

## Платформы и архитектура

- **Первая платформа:** браузер. Приоритет - Safari на macOS и Chrome/Edge на Windows.
- **Первый язык интерфейса:** русский.
- **Расчёты:** локально в браузере, без обязательного сервера, учётной записи или подключения к OCI.
- **Предлагаемый стек:** TypeScript, React, Vite, Web Workers, IndexedDB; конкретные зависимости утвердим на M0.
- **Переносимость:** экспорт/импорт сохранений, версионирование данных и движка; отдельное приложение для macOS и Windows возможно позже.
- **Данные:** исходная база и состояние карьеры разделены. Реальные футболисты, клубы и символика могут включаться только при подтверждённых правах использования.

## Первое реализованное ядро

В M0 реализована отдельная TypeScript-библиотека без браузерных зависимостей: версии моделей и валидация вымышленных клубов/футболистов, тестовая база из 16 клубов и 368 игроков, календарь 30 туров и проверка его полноты, воспроизводимый генератор случайных чисел, проверяемый экспорт/импорт стартовой карьеры, контракт журнала событий матча с выводом статистики. Это **не** генератор футбольных матчей и **не** играбельная версия. Браузерная оболочка и прототип IndexedDB реализованы, но реальное браузерное тестирование, миграции и симуляция матчей пока не завершены.

После установки Node.js 24 и npm в рабочей копии:

```bash
npm ci --ignore-scripts --no-audit --no-fund
npm run dev         # локальный Vite, http://127.0.0.1:5173
npm run check       # типы, headless-тесты, production-сборка оболочки
```

Браузерная оболочка на React/Vite позволяет выбрать вымышленный клуб, посмотреть начальный календарь, создать стартовую карьеру, экспортировать/импортировать её JSON и проверить локальное восстановление IndexedDB. Матчи ещё не рассчитываются, игрового сезона и релиза нет. Никакие серверные сервисы не обязательны.

Команда проверяет TypeScript, ESLint, исходное форматирование, компилирует доменные контракты, запускает тесты и собирает браузерную оболочку. Импорт синтетической базы и стартового сохранения имеет проверки размера, схемы и целостности. Полная проверка правил РПЛ, реальные источники данных, браузерное сохранение и многосезонная карьера ещё не реализованы. См. [границы прототипа сохранения](docs/SAVE_PROTOTYPE.md).

## План

| Этап | Цель |
| --- | --- |
| M0 | Архитектура, спецификации, юридическая чистота данных, начальные проверки |
| M1 | Детерминированный расчётный движок матчей |
| M2 | Играбельный сезон РПЛ и сохранения в браузере |
| M3 | Контракты, трансферы, финансы и управление клубом |
| M4 | Долгосрочная карьера и развитие футбольного мира |
| M5 | UX, доступность, производительность и PWA |
| M6 | Стабильный релиз; при необходимости приложения macOS/Windows |

Полные задачи, актуальный прогресс и обязательные итоговые аудиты находятся в [ROADMAP.md](ROADMAP.md). Ни один milestone не считается завершённым без полного аудита/рефакторинга/код-ревью репозитория, второго прохода и финальных проверок по [AGENTS.md](AGENTS.md).
