# New-career opt-in special-goal source (temporary schema bridge)

**Work in progress, not yet accepted P3/P5 or a new stable release.** The owner approved changing the simulation and save architecture on 2026-11-10 ([ADR-0012](adr/0012-owner-approved-architecture-evolution.md)). This incremental bridge uses a **versioned match-source discriminator** `specialGoalSourceVersion:1|2` on an existing source-backed v188 JSON entry. It is **not** a permanent commitment to v188 IndexedDB layout; a new canonical career/save version is authorized and planned.

For the test preview, a **fresh career at revision 0** now selects source version 2: the v190-derived internal special-decision model for penalties and own goals combined with the v191 opt-in shot hypothesis. Earlier version-1 careers continue the originally deployed uncalibrated shot model. The underlying authentic synthetic physical sequence, v184 referee/medical incidents, formation/tactical input, xG, manager commands and goalkeeper checks are preserved. The new result is independently regenerated from the canonical prematch, source commands and physically present players. Stored `result` and goal-source version must pass the versioned replay verifier. A forged goal count, modified decision or changed source version fails; no caller-provided referee assertion can authorize arbitrary special events. A complete 240-fixture native Chrome/Edge/Safari UI run now also asserts source version consistency, score/event conservation, and **nonzero verified penalties and own goals**, with observed counts logged for calibration research.

An **already started career** stays on its original source version for all 240 fixtures. No silent rewrite/migration of existing 2026-11-09 archives; existing full-career export/restore remains available. Old test careers may be intentionally reset rather than migrated under the owner-authorized disposable preview-save policy. The versioned flags let one browser load and restore the legacy career and newly created career without misattributing old results.

**Important limitations:** the new v191 shot multipliers (1.08/0.60/0.68) and the v190 experimental rates (`0.26` chance of one penalty and `0.06` of one own goal per fixture) are provisional **test parameters**, not source-validated real-RPL incidence and not compatible with a final calibration claim. New events must be measured in multi-seed 240-match cohorts and calibrated together with the existing over-high open-play goal rate and card distribution. Real foul/penalty-area triggers, law-based retakes, restart decisions, player eligibility, full M2 adjudications and official referee authority are **not** established. This bridge should remain DRAFT until typecheck, entire 240-match Chrome/Edge/Safari browser seasons, archive restoration and user observation are verified; old v188 careers are not deliberately rewritten by this patch, but long-term preview-save compatibility is not required. #155 and M1/M2 exit remain OPEN.
