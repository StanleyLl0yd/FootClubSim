# M2 rule prototype: RPL 2026/27 Article 18 ranking

**Status: opt-in, read-only source research; not M2 accepted.** This module does not replace or mutate the accepted v188 fictional league's provisional 3/1/0 ranking, the signed save format or the current public UI.

`src/core/m2-rpl-2026-standings.ts` consumes 16 caller-supplied club IDs and bounded, distinct, directed played-fixture results. It computes points, overall wins, difference, goals, away wins/goals and head-to-head mini-tables for each group on equal points. For current standings only, unequal mutual fixture counts disable head-to-head metrics. With trustworthy complete **caller-supplied** inputs it can also compare disciplinary points (fewer is better) and prior-season positions for an unresolved current table.

It does **not** fill missing disciplinary information with zero, use stable IDs as an official last tie-breaker, invent the prior year's ranking or assume a definitive champion when the final standings need an extra match/tournament. The result carries `ARTICLE_18_RESEARCH_ONLY_NOT_OFFICIAL`, separated unresolved rank groups and explicit reasons `MISSING_DISCIPLINE`, `MISSING_PREVIOUS_SEASON` and `EXTRA_MATCH_REQUIRED`. A final-season claim requires 240 distinct home/away games and 30 played games per club. This adapter assumes the caller verified the fixture source and rules edition; a passed tuple is not a signed federation decision.

**Rules reference:** [RPL 2026/27 primary RFU document no. 2164, art. 18.1, 18.3–18.7](https://www.rfs.ru/subject/1/documents/preview?documentId=2164), extracted/veracity caveats in [project's source review](RPL_2026_27_RULES.md). The project has not verified later amendments, official KDK appeals, authoritative card/disciplinary feed, valid club registrations, last-season position evidence, or extra-match adjudication. Therefore this is a concrete stepping stone, **not an executable complete M2 competition rules pack**.

**Tests:** H2H precedence over total goal difference, unresolved all-equal and incomplete tables, prior-season fallback only after known disciplinary scores, exact 240-match full-season completeness, unknown or duplicate fixture refusal, no input mutation.
