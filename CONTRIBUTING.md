# Contributing

FootClubSim is public-source **All Rights Reserved** software, not an open-source licensed project.

Issues with reproducible bug descriptions, architecture discussions and gameplay suggestions are welcome. The repository owner may decline unsolicited pull requests because accepting external code requires an explicit rights arrangement.

Before submitting substantive code or artwork, contact the repository owner and confirm licensing/assignment terms; do not assume that publishing a PR transfers copyright or that every publicly visible source is reusable. Do not include scraping outputs, unlicensed rosters, club badges, player photographs, secrets or private saves.

Maintainer changes follow [AGENTS.md](AGENTS.md): short-lived branches, reviewable PRs, tests, protected behavior and full repository-wide exit audits for each milestone.
