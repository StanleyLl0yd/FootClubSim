# M1 P3-1/P3-2 playable synthetic medical source (v176)

This addition integrates the existing seeded v23 fictional referee/treatment
generator into **one v105 physical-XI shot and goal chronology**, with
source-regenerated referee incidents, treatment departure and re-entry, and
a single v120 journal/CAS admission path. It does not fork the old v8
persistent journal or change existing M0, v8 or v120 save schemas.

The v176 namespace requires the exact seeded generated referee commands and
medical actions, identical to regeneration at both insertion and historical
replay. v126 projects source-verified fictional holds and rejects historical
held-player bypass; v171 rejects forged source identity before IndexedDB put.
Every accepted v105 event remains source-replayed.

This narrow prototype does **not** authenticate real referee, medical, KDK
or return permissions. A simulated 300-second absence is not a clinical
diagnosis. Goalkeeper/collision/severe-injury/penalty-taker Law 5 exceptions,
concussion competition adoption, bleeding, full 240-match opponent history,
arbitrary stoppage/manager windows and true calibration remain open. No real
football data or 2024/25 holdout is used. **P3/P5 NOT ACCEPTED.**
