# M1 P3/P5 v120 — versioned dense-source career journal (pure domain)

This is the first **integrated source-to-career boundary** for the existing
100-second/three-shot-slot v103/v105 engine. It deliberately does **not**
overwrite or reinterpret the historically replayed **v8 schema-4** match
journal. The dense v105 source already independently rechecks v103
physical XI/medical transitions against v8 checkpoint inputs and
composes special-goal decisions in one causally ordered event list.

The new **schema 120** journal:
- Binds every recorded fixture to the next scheduled controlled-club round;
- Accepts only an exact source-replayed v105 result and the immutable original
  M0 catalog, retaining all actual 270 shot RNG draws;
- Omits the fixed M0 catalog from each stored source record, reconstructs it
  for every independent full-history replay;
- Tracks a pure expected-revision CAS, rejects duplicate commands,
  forged outcomes, wrong fixture/catalog and mutated historical records;
- Captures no third-party clinical or official referee authentication;
- **Does not yet perform a native browser IndexedDB transaction.** It is
  *not* the new playable career until a separate versioned browser store/UI
  connects to this journal and executes full native restart/recovery tests.

Do **not** silently migrate v8 careers or overwrite their result history.
The future browser integration must coexist in a separate storage namespace
or use an explicitly consented, source-replayed migration with rollback.

This removes a major engine-level structural blocker: unlike the current
18-slot playable v8 source, v105's 3×100-second subslot engine has up to
54 possible *open-play* shots, with source-preserving physical transitions,
and allows statistical P5 calibration after validated taxonomy and
independent reference. The source is **not calibrated** by this change;
the 2024/25 holdout remains sealed. No P5 realism acceptance,
browser durability or external medical authorization is claimed.
