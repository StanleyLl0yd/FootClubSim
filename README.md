# ⚽ FootClubSim

> **Football Manager от Sports Interactive и SEGA.** Из года в год новая цифра в названии, а по-настоящему свежих идей кот наплакал, да и те толком не развивают. После отменённого FM25 и FM26 с интерфейсом, который будто специально делали назло игрокам, терпение окончательно закончилось.
>
> **Решил сделать свой футбольный менеджер. С шашками и пионерками.**

## Что за FootClubSim?

**FootClubSim (Football Club Simulator)** - браузерный симулятор управления футбольным клубом.

Идея проста: дать игроку возможность заниматься футболом, а не поисками нужной кнопки в пятом уровне вложенности меню.

Состав, тактика, трансферы, контракты, финансы, персонал, развитие клуба и многолетняя карьера. Решения принимает менеджер, последствия рассчитывает игровой движок.

Никаких обязательных трёхмерных человечков, бегающих за мячом. Матчи рассчитываются автоматически, а желающие смогут вмешиваться в происходящее: менять тактику, проводить замены и раздавать индивидуальные указания.

Разумеется, указание «перестаньте уже пропускать на 90-й минуте» не гарантирует результата.

## 🏆 Лига приколов

Начинаем с вымышленной **«Лиги приколов»**, вдохновлённой российской Премьер-лигой.

Здесь за чемпионство будут бороться **Надир**, **Зеленобер**, **Вагон**, **Патриций**, **ОГКМ**, **Пацифика**, **Статика М1**, **Статика М2** и ещё восемь достойных представителей отечественного футбольного абсурда.

Всего 16 клубов, 30 туров и 240 матчей за сезон.

Названия, эмблемы и игровые персонажи будут вымышленными, но футбольные правила мы стараемся брать из настоящих регламентов РПЛ, РФС и IFAB. По крайней мере, там, где эти регламенты удаётся понять без помощи адвоката.

## 🎩 Ты здесь главный. Почти.

В планах полноценная карьера футбольного менеджера:

- **Создай себя.** Бывший профессиональный футболист, футбольный теоретик или самородок с самостоятельно распределёнными характеристиками. Вымышленная биография прилагается.
- **Собери команду.** Выбирай состав, расстановку, тактику и роли футболистов.
- **Управляй матчем.** Наблюдай за событиями, вмешивайся в нужный момент или доверь всё автоматическому расчёту.
- **Руководи клубом.** Контракты, трансферы, тренировки, скаутинг, бюджет и персонал.
- **Делегируй обязанности.** Не хочешь лично заниматься каждой мелочью? Поручи работу сотрудникам. Потом выяснишь, кому именно не стоило доверять.
- **Строй карьеру.** Сезоны сменяют друг друга, футболисты взрослеют, команды меняются, а руководство по-прежнему ждёт результата.

Главный принцип: не просто показывать красивые цифры, а рассчитывать, как характеристики футболистов, тактика и принятые решения влияют на происходящее.

## 🔧 Что уже работает?

**Проект находится в активной разработке. Полноценной играбельной версии пока нет.**

Реализованы:

- Базовая футбольная модель, синтетическая лига из 16 клубов и календарь сезона.
- Браузерная оболочка с выбором демонстрационного клуба, календарём и первоначальной карьерой.
- Экспорт, импорт и прототип локальных сохранений через IndexedDB.
- Экспериментальный расчётный движок с тактикой, игровыми эпизодами, голами, карточками, заменами и медицинскими событиями.
- Воспроизводимый расчёт матчей: одинаковые исходные условия и seed дают одинаковую историю событий.
- Проверка согласованности результатов, статистики и сохранённой истории.

Расчётный движок пока работает отдельно от полноценного браузерного игрового процесса. Это ещё не та версия, где можно выбрать «Надир» и через час уволить половину состава.

**Текущий этап: M1, разработка и проверка движка матчей.**

Следующая большая цель - первый полноценный игровой сезон в браузере.

Подробности и планы: [ROADMAP.md](ROADMAP.md).

## 💻 На чём всё это работает?

- **TypeScript** - игровая логика и расчётный движок.
- **React + Vite** - браузерный интерфейс.
- **IndexedDB** - локальное хранение игровых данных.
- **GitHub Actions + CodeQL** - автоматические тесты, сборки и проверки безопасности.

Приоритетные браузеры: Safari на macOS, Chrome и Edge на Windows.

Игра проектируется как одиночный браузерный симулятор с локальными расчётами, без обязательного игрового сервера и регистрации пользователя.

Серверную ферму ради того, чтобы «Вагон» проиграл «Надиру», поднимать не собираемся.

## 🚀 Как запустить

Понадобятся **Node.js 24** и npm.

```bash
git clone https://github.com/StanleyLl0yd/FootClubSim.git
cd FootClubSim

npm ci --ignore-scripts --no-audit --no-fund
npm run dev
```

Открой в браузере:

`http://127.0.0.1:5173`

Для запуска полной локальной проверки:

```bash
npm run check
```

Это пока демонстрационная оболочка и техническая основа игры, а не готовый Football Manager с шашками и пионерками.
