# M1-P4: ненормированная сезонная статистика v6

Отдельная **read-only** проекция `deriveM1V6UnrankedSeasonTotals`
принимает только валидированный результат
`validateM1V6MatchJournal` схемы 2 и исходный M0 catalog.

Для каждого клуба в неизменённом порядке стартового каталога
аккумулирует матчи, победы/ничьи/поражения, экспериментальные очки
3/1/0, голы, удары, удары в створ, xG (тысячные), карточки,
удаления, подтверждённые медицинские выбытия, обычные замены и
секунды на поле. Проверяет сохранение суммы голов, очков,
двустороннее число участий и базовые числовые инварианты.

**Это не таблица РПЛ по официальным критериям.** Нет сортировки,
тай-брейков статьи 18, дополнительных матчей/решений КДК,
межматчевых дисквалификаций, последствий медицинских выбытий,
сезонного сохранения, real-roster или калибровки. M1-P4 #30
остаётся открытым. Модуль не меняет старые отчёты v5 или M0.
