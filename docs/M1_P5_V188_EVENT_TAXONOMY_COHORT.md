# M1 P5: source-verified four-season v188 event taxonomy census

**Status: diagnostic, not statistical calibration.** The accepted current v188 preview preserves its synthetic original teams, tactics, event source and saved career format. This test does not copy owner private exported career files, sample real providers, or update game scores.

The existing `scripts/m1-v188-season-diversity.mjs` already runs **four independent 240-fixture seasons**, validates each entire journal by regenerating original source events and verifies all 16×30 match outcomes. The new census adds per-seed totals for source-reported open-play goals, penalty attempts and successful penalties, own goals awarded, synthetic yellows, straight reds, second-yellow dismissals, and fictional injury withdrawals. It also records source-verified observed per-match goals/shots/cautions/dismissals and checks that all reported goals are exactly reconciled with the event stream and official *fictional* provisional table. Results are written into the existing anonymized `season-diversity-report.json` and GitHub Actions summary; no real names or raw archive added.

**Known and now source-confirmed gap:** `src/core/m1-v182-unified-source.ts` calls `simulateM1V105SpecialGoalChronology(...,[],[])` with an always-empty final `trustedDecisions`. While the v105 chronology recognizes `penalty-kick` and `own-goal` in independently provided decisions, v188 does **not automatically generate** those decisions. Their zero rate is **structural in v188**, not merely an unlikely statistic for one user's season. See [#31](https://github.com/StanleyLl0yd/FootClubSim/issues/31).

Do not interpret these event totals as real football rates. The current source does not provide authenticated IFAB referee decisions, actual RPL KDK disciplinary orders, true player injury diagnoses, or licensed external benchmark distributions. No externally proven probabilities or pre-registered tolerances exist; the 2024/25 holdout remains closed for model tuning. Specific observed per-match rates and variation can support *future* design and test contracts, but **P3/P5, M1 and M2 remain open**.

**Next build requirement:** introduce independently tested, versioned internal referee event provenance for penalties and own goals, with explicit physical-player eligibility, causal event timestamps, scorer/beneficiary attribution, deterministic replays and scoring invariants. Preserve v188 historical bytes; no patching of completed past results. Then run independently seeded and mirrored source-verified cohorts with rights-reviewed reference definitions and pre-registered acceptance bands. Avoid claiming a random incident added to a saved match is genuine referee authority.
