# M1 P3: interactive referee-authorized substitutions

The playable browser manager may now substitute one player at a virtual
in-match pause, using the **same source** as automatic matches, earlier
tactical orders and physical on-field XI. A coaching pause alone is not a
substitution window. The selector is enabled only at canonical half-time or
a source-verified goal/referee stoppage at the exact chosen second.

The source-derived picker excludes previously removed/used players, players
off the physical field (dismissal or medical absence), incompatible
goalkeeper/outfielder swaps and pairs exceeding the foreigner cap. It also
tracks the existing five-replacement/three-in-play-window constraints.
The actual v188 generator and atomic CAS independently verify manager
authority, referee stops, full event replay and immutable played prefixes.
No advance disclosure of future source events or scores is provided.

No persisted schema changes, external referee/medical authority or complete
official RPL exception coverage are asserted. This is functional P3 progress
and is **not** P3-2/P3-3/P3-4 or M1 exit acceptance. Holdout 2024/25
remains sealed.
