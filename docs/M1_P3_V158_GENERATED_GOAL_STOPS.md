# M1 P3 v158 — source-generated goal restart for dense normal changes

Earlier dense v138 proves legality of five ordinary manager-selected
substitutions at 300-second boundaries, but its `referee-authorized`
stoppage label is **not** authenticated. A self-declared label must
not turn any arbitrary checkpoint into a generated fictional whistle.

This opt-in **versioned** adapter admits 1–5 normal selected changes only
at halftime (the distinct lawful exemption) or at a 300-second boundary
**immediately after a seed-generated open-play goal at second
299, 599, ...**. Each distinct in-play window independently recomputes
the *same v105 source* with only the earlier substitutions present;
this prevents a later goal from an obsolete eleven-player future source
from granting a new stoppage. At a joint window, one source-generated
goal permits already-validated simultaneous substitutions.

Accepted commands use a distinct `v158-goal-multi-<fixture>` outer
namespace and `v158-sub-<fixture>-<index>` source identities. The v126
historical-hold reviewer rechecks those exact identities and each
goal-source prefix from the saved journal. The v120 generic CAS now **prechecks exact v158 command identity,
the v122 canonical fixture-derived seed from the immutable initial
career RNG state, and regenerates every claimed goal stop before any
journal append**, while its
normal source simulator independently replays the final physical XI,
RNG, shots and result. The same gate executes again on journal reload;
invalid v158 claimed authority can neither be stored nor revived. Imaginary goal stops fail closed; old v138 sources
are still separately recognized as **unverified referee-origin**
manager changes, not silently upgraded.

**v161 extension:** single and paired manager changes now reuse the
existing v132 and v136 legal player/bench admission paths; batches of
3–5 still use v138. All 1–5 changes converge on the same v158
source-generated stoppage proof, v120 CAS and v126 historical recheck,
with no new save format or hidden change to earlier v132/v136/v138 claims.

Only source-replayed fictional **goal/halftime** stops are admitted.
Fouls, out-of-play, timed departure, fourth-official procedures,
100-second substitutions, real referee/medical/KDK authority and full
opponent history remain unsupported. This is incremental P3-1 progress,
**not** a closed block or complete 2026/27 IFAB acceptance. M0/v8/v120
save formats, existing historical source records, rules, RNG and the
sealed 2024/25 holdout remain unchanged. P3 4/P5 5, M1 and exit #3 0/2
remain OPEN; M2 prohibited.
